# Barangay Information Webpage (Task 1: Project Definition)

1. **Title:** Barangay Maligaya Information Page (sample data)
2. **Problem or need:** Residents often do not know the latest announcements, who to approach, what a document costs, or whether the hall is open. They travel to the hall only to learn requirements are missing.
3. **Target users:** Residents (students, workers, senior citizens), and barangay staff who answer repeated questions.
4. **Objectives:** (a) Publish announcements that are easy to search; (b) show officials and contacts clearly; (c) let residents estimate fees and prepare a document request; (d) work well on phones, tablets and desktops.
5. **Main features:** live hall open/closed status; announcement search and category filter; officials search and sort; fee calculator; validated document request form saved in localStorage with remove and clear; emergency contacts.
6. **Planned sections:** Home, Announcements, Officials, Services, Request a document, Contact.

Files: `index.html`, `login.html`, `signup.html`, `css/style.css`, `js/script.js`, `js/auth.js`. Log in and sign up are frontend demonstrations (accounts kept in localStorage, passwords hashed with SHA-256 in the browser; not real security). Open `index.html` in a browser (internet needed for Bootstrap and fonts). The request form is a frontend demonstration only.
